# SwiftQuantum Core

Swift package: Clifford (stabilizer) simulator up to 127 qubits, exact dense statevector for small circuits, OpenQASM 2.0 and Stim import and export. It is a simulator, not quantum hardware. Stim is the reference. See the README table "What this package is and is not" before changing any claim.
